# M5 계획 예산 예약

> 현재 구현·검증 상태: [성장2 후속 완료 기록](META-EXECUTION-M5.ko.md). 아래 준비 단계 설명은 실제 실행 경로와 구분한다.

현재의 예산 검토(`plan_scope_only`)와 별도로, 15분 이내 읽기 검증한 외부 광고 구성에 로컬 계획 예산을 예약한다. **예약은 실제 집행 승인·공급자 청구 상한·외부 광고 중단이 아니다.** `maySpend:false`를 API와 화면에서 유지한다.

- 기록 kind `meta_ads_reservation`: 계정·광고세트·전체 구성 scope digest와 검증 시각, 원화 예약액·총 예산·안전 여유·손실 한도·중단 기준, 생성/해제 행위자와 판을 저장한다. 외부 광고 원본·고객 정보·토큰은 저장하지 않는다.
- 소유자 전용, CSRF, owner 잠금. 같은 광고세트 또는 캠페인의 미해제 예약이 있으면 새 예약을 거절한다. 동일 입력 재시도는 기존 기록을 반환한다. 외부 결과 미확인 상태는 해제할 수 없다.
- 시작 전 최대 31일, 정수 원화 금액, 안전 여유 제외 범위, 현재 계획·소재·부모·연결·외부 구성 변경을 확인한다. 과거 검증은 현재 PAUSED 상태의 보증이 아니며 실제 활성화 경로는 제공하지 않는다.
- 로컬 해제는 판·원문 CAS로 비교한다. 예약/해제 이력이 있으면 캠페인 삭제를 거부하고 보관을 안내한다. 1,000건 도달 시 새 예약을 저장 전에 거부하여 기존 조회·해제를 유지한다.
- 프런트엔드는 조회·쓰기 중 잠금, 확인 체크, 오류 시 입력 보존을 제공한다. “로컬 예약 해제”가 Meta 정지인 것처럼 표시하지 않는다.

검증: 순수 금액/기간/중복 조건과 실제 메모리 SQLite의 성공·멱등·동시 요청·권한·CSRF·계정/캠페인 격리·해제 CAS·한도 경계. 외부 구성 확인은 합성 fixture, 실제 Meta 호출은 0이다.

남은 개발과 실운영 전제: 원본 소재의 공급자 업로드 동일성, 광고세트/광고 생성, 공급자 예산 단위·실제 한도, 별도 지출 승인, 예약 금액 사용·정산, 활성화·긴급 정지·결과불명 재대조·서버 작업자 감시. 이 단계가 없으므로 예약만으로 운영 광고비를 쓰지 않는다.
