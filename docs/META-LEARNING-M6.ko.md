# M6 보고에서 다음 실험으로

성과 대조에서 기록한 보고를 선택해 보류·중단·재실험·계속 관찰이라는 사람의 판단을 남긴다. 재실험은 같은 캠페인의 현재 소재를 선택하고 가설·바꿀 한 가지·대조안·실험안·지표·최소 표본·종료 기준을 채운 준비 초안이다. 구매 지표가 없는 기존 바이럴 실험에 이를 억지로 넣지 않는다.

- `meta_ads_learning_decision`은 보고 ID/판/digest, 캠페인 판, 판정 근거와 선택한 소재 ID/판/파일 hash를 보존한다. 같은 요청은 멱등이며 다른 내용은 새 판정 이력이다.
- 저장 전에 같은 기간의 주문·성과를 다시 대조한다. 환불·추가 주문·성과 개정 뒤에는 새 보고를 기록해야 한다. 조회에서는 이전 판단을 삭제하지 않고 낡은 근거를 표시한다. 소재 버전·파일·사실의 유효성 변경도 표시한다.
- 워크스페이스 소유자·관리자만 기록한다. CSRF·캠페인 범위·owner 잠금·판 비교를 적용한다. 직원은 읽기만 가능하다.
- `evidenceStatus`는 자료 부족 또는 관찰 자료일 뿐이다. 계속 관찰이 지출 권한을 부여하거나 재실험 후보가 완료 실험·승자·증분 근거로 승격되지는 않는다. 규칙 자동 활성화와 외부 호출은 없다.
- 보고와 판단 이력은 최근 20개를 읽으며, 이력에 참조된 이전 보고도 대조한다. 캠페인 삭제 정책은 보고와 함께 삭제다.

검증은 `tests/meta-learning.test.mjs`와 `e2e/meta-learning.spec.ts`. 로컬 SQLite/브라우저 및 모의 인증을 사용하며 실제 광고 효과 검증이 아니다. 외부 전송·유료 모델 실행 0.

남은 개발: 후보를 실제 사전등록 실험으로 시작하는 승인 경로, 배정·관측기간·전환 성숙·원가/세금 기준과 통계 판정, 검증된 결과의 규칙 후보 연결. 이번 초안은 이 단계를 완료했다고 표시하지 않는다.
