# 성장2 자사 장부 감지 신호

대상 카드: G2-06(허용 시장/경쟁/자사 신호·신선도)·G2-07(신호→기회·캘린더, 기한·다음 행동)·G2-25(기회 발굴). 외부 수집·모델 호출 없이 **자사 장부에서 결정론적으로** 검토 신호를 만든다. 외부 시장 자료는 기존 [확정 시장자료 가져오기](GROWTH-2-SIGNAL-SOURCES.ko.md)를 쓴다.

| 종류 | 규칙(고정 임계값) | 근거 |
|---|---|---|
| 주문 증가·감소 | 최근 7일 일평균 유료 주문 vs 직전 21일 일평균 ±50% 이상, 최소 5건 규모. 전액 환불·취소 제외. 기준 기간 주문 0이면 비율을 만들지 않음 | 캠페인 지점 `store_order` |
| 품절 위험 | 공유 재고 가용 ÷ 최근 7일 출고 일평균 ≤ 3일. 재고 보류·출고 0은 제외 | 공유 재고 원장·`ship` 사건 |
| 반품 원인 반복 | 최근 30일 같은 운영자 확인 원인 3건 이상(미확인 제외, 사건 수) | 반품·환불 원인 기록 |
| 문의 유형 반복 | 최근 30일 같은 문의 유형 3건 이상 | [고객 문의](GROWTH-2-CS.ko.md) |
| 시즌 일정 | 45일 안의 설날·추석·밸런타인·화이트데이·어버이날·빼빼로데이·블랙프라이데이·크리스마스(2026~2028 날짜 고정, 없는 해는 추측하지 않음), 준비 기한 = 7일 전 | 코드 내 달력 |

- 감지 키(종류+대상+기간)가 같은 신호는 한 번만 만든다. 기존 신호는 상태와 무관하게 다시 열거나 덮지 않는다.
- 신호는 `new → acknowledged(담당·다음 행동·기한) / dismissed(사유)`. 기한이 지난 담당 신호는 표시한다. 수요 예측이 아니다(`isForecast:false`).
- 수동 “지금 감지”와 [일일 운영 루프](GROWTH-2-DAILY-LOOP.ko.md)가 같은 함수를 쓴다.
