# 성장2 수요 시퀀스 — G2-27

성장2 원안의 메시지·사용 장면·소재·검색어·대상·크리에이터/제휴 계획을 기존 오퍼와 판매 미션에 연결한다. 시작 기준은 main `f0195109b2370913dc502e3412eaf54c681a3db7`(#266/#267 병합), 작업 브랜치는 `codex/growth2-demand`다.

## 사용과 증거

캠페인 → 성장·판매 → 수요 시퀀스·콘텐츠·협업에서 작성한다. 계획 하나에 현재 오퍼와 미션을 연결하고 최대12개 단계의 순서를 편집한다. 단계별 채널/노출 방식, 전달 메시지, 사용 장면, 콘텐츠 제작 지시, 검색어, 대상 고객 가설, 구매 URL, 공개 출처, 사용 권리, 협업 역할/조건, 계획 비용, 운영자 성과 관측을 기록한다.

빈 비용은 미확인(null)이고 명시한 0원은 무상이다. 한 단계 비용은 0~1e12원 정수다. 일부 비용이 미확인이면 전체 계획 비용도 미확인으로 표시한다. 알려진 비용만으로 미션 예산을 초과해도 준비를 보류한다. 여러 계획의 합산 예약·지출은 이 화면에서 수행하지 않는다.

권리 확인과 진정성 확인은 운영자 검토다. 가짜 참여·후기 없는 계획임을 확인하지 않았거나 명백한 조작 지시 패턴이 있으면 준비를 보류한다. 명시적인 문구 검출이며 모든 의미/문맥을 판별하는 자동 검수는 아니다. 외부 실행 시 채널 정책·권리·진정성을 다시 검토해야 한다. '가짜 후기 금지' 같은 금지 안내 자체는 조작 지시로 처리하지 않는다.

성과 기본값은 미측정이다. 운영자 관측을 선택하면 근거와 설명이 모두 필요하지만 매출·수요 검증·인과 기여로 승격하지 않는다. 계획이 준비돼도 `mayExecute:false`이며 외부 광고·게시물·메시지·협업 요청을 전송하지 않는다.

## 참조·준비도와 저장

`GET/POST /api/growth/demand`의 `save_sequence`는 관리자 쓰기, CSRF, 소유자 잠금, 캠페인 판과 시퀀스 판, 같은 캠페인/브랜드의 오퍼·미션 및 정확한 참조 판을 검사한다. 미션과 시퀀스의 오퍼도 같아야 한다. 연결 전 초안은 저장할 수 있으며 준비는 보류한다. 보관 캠페인은 조회만 허용한다.

기존 growthView의 상위 준비도를 재사용한다. 상품 사실·시장 근거·니즈·상품·오퍼·미션이 바뀌면 준비 상태가 재계산된다. 오퍼/미션의 버전을 자동으로 최신으로 덮지 않고 사용자가 명시적으로 다시 연결한다. 결과 불명·실패·취소 미션도 준비를 보류한다.

동일 내용·판의 재전송은 중복 저장하지 않는다. 변경 충돌 시 UI 초안을 보존하며 새로고침은 서버 기록만 갱신한다. 최신 기록을 검토한 뒤 사용자가 명시적으로 저장 기준을 바꿀 수 있다. 추가 전용 `growth_demand_history`와 현재 `growth_demand`를 같은 D1 batch에 저장한다. 두 kind는 campaign parent의 로컬 계획이므로 캠페인 삭제 시 함께 지우며 실행 이력 삭제 규칙에 영향을 주지 않는다.

캠페인별500개를 넘는 새 시퀀스는 쓰기 전에 거부한다. 공개 URL은 HTTPS, 인증정보·쿼리·해시·내부 호스트·IP 없이 입력하며 중첩 인코딩의 개인정보/인증정보 패턴도 검사한다. URL을 서버에서 가져오지는 않는다. 본문은 개인정보/인증정보 검사를 거치며 원시 고객 데이터를 담지 않는다.

## 수용 검사와 남은 범위

전용 도메인/API 검사는 초안·순서·미확인 비용·파트너 조건·진정성·권리·URL, 범위/권한·CSRF·CAS·멱등·상위 변경·한도·이력을 검증한다. 실제 로컬 브라우저 검사는 단계 순서 저장·재조회, null과0, 동시 수정 입력 보존, 화면 너비를 확인한다. 최신 명령 결과는 STATUS에 기록한다.

G2-27 전체의 실제 채널 실행·소재 생성·협업 계약·반응 수집은 잔여다. G2-19 수요 캠페인 전체 완료로 표시하지 않는다. 다음은 G2-29 구매 병목, G2-11/31/32 결정·운영 교훈, G2-14 동의 기반 재구매와 G2-28/12a 일반 판매 실행 연결이다. 조건부 카드를 삭제하지 않고 원안33개 전체를 계속 추적한다.
