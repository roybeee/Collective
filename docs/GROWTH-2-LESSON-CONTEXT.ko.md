# 성장 교훈의 실제 작성 연결

같은 소유자·브랜드·캠페인의 현재 교훈 중 기존 `lessonAssessment.canReuse`를 통과한 방법을 AI 역할 작성 입력에 전달한다. 캠페인·원 미션·상품·근거가 개정되었거나 만료·철회된 교훈은 제외한다. 전역 중단 중에는 새 교훈을 적용하지 않는다.

CMO·전략·제작·콘텐츠·성장·분석·검수 역할이 대상이며 최대 5개, 본문 8,000자까지 전달한다. 원래 재사용 승인은 유지하며 프롬프트 레지스트리나 성과 규칙을 자동 활성화하지 않는다. 성공 방법은 검토 참고, 실패 방법은 회피·재검증 참고다. 운영 관측은 인과 효과나 광고 표현의 사실 근거가 아니다.

정확한 교훈 ID·판·본문 digest를 역할 계약과 작업물에 남기고 실제 공급자 요청에는 방법·범위·반증·폐기 조건을 보낸다. 담당자와 연락처를 보내지 않으며 수동 평가 동결 요청도 입력 경계에서 검증·가림을 거친다. 참고한 교훈은 실제 요청 해시에 포함되어 기존 요청과 혼동되지 않는다.

AI 완료 후와 작업물 재조회·승인 때 출처를 다시 검사한다. 변경·만료·철회가 있으면 `성장 교훈 변경` 표시와 명시적 변경 확인이 필요하다. 확인은 당시 출처 상태 digest에 묶이며 새 개정 뒤에는 다시 검토한다. 사람이 작업물을 고쳐도 원래 참고 이력은 남는다. 적용 효과는 기존 교훈 적용 결과 원장에서 별도로 확인하며 작업물 승인을 판매 효과로 집계하지 않는다.

검증: `tests/growth-lesson-context.test.mjs`는 실제 SQLite와 합성 HERMES 공급자를 사용하여 요청 전달·계약/작업물 저장·철회 후 경고·확인 없는 승인 거절·개정 후 재검토·수정 시 이력 보존을 확인한다. 실제 모델 품질·판매 효과 검증은 별도다.
