# 브랜드 인터뷰 스튜디오

대표 요청(2026-09-27): 마케터가 담당자/점주를 풍부하게 인터뷰하고, 자료·녹음을 남겨 캠페인의 첫 근거로 사용한다. 성장1 마감 조건을 늘리지 않는 별도 제품 기능이다.

## 구현 범위

- 필수 8개 섹션, 추가 질문 24개. 미입력/짧은 답변을 기반으로 다음 질문 추천. 수기 답변·인터뷰 제목·응답자 역할 저장.
- TXT/MD/PDF/DOCX/CSV/JSON/이미지 및 MP3/WAV/M4A/MP4/WEBM/OGG 드래그앤드롭. 파일당 8MB, 인터뷰당 20개. 기존 비공개 R2 업로드·다운로드·삭제 사용. 텍스트는 서버 추출, PDF/DOCX는 기존 브라우저 추출 출처 표시, 스캔 자료는 수기 보완.
- 브라우저 MediaRecorder 녹음·타이머·미리듣기·로컬 다운로드·원본 보관. 마이크 거부/미지원은 오류 안내. 참여자 동의 확인. 브라우저 종료 전 미저장 경고, 탭 전환 시 인터뷰 유지.
- HERMES 정리: 원문 PII 패턴 가림, 자료 100,000자 상한, 기존 예산 예약/멱등 제출/사용량 원장. 입력에 있는 연속 인용만 허용하는 구조 검증. 미확인 답변은 자동 사실 확정하지 않는다.
- 섹션 후보 선택 반영은 기존 답변에 추가(덮어쓰기 없음). 원문 인용·자료 ID 유지. 관리자 아카이브 확정 후 기존 캠페인 근거 경로를 사용한다.
- 녹음 전사: 별도 로컬 음성 서비스 구현과 능력 협상 어댑터. 표준 HERMES API 기능이 아니며 설치/운영 검증이 남아 있다. [설치 문서](../server/interview-transcriber/README.md).
- Plaud: 내보낸 TXT/MD 전사문 첨부 지원. **Plaud MCP 직접 녹음 목록/전사 조회는 이번 코드에 구현하지 않았다.** 현재 ChatGPT의 Plaud 연결을 배포 앱이 자동 사용할 수 있다고 가정하지 않는다.

## 데이터와 권한

`brand_source` 확장 필드 `interview`: 역할, 섹션 답변, 첨부 source ID, 후보, HERMES 작업 상태/근거 스냅샷. 신규 kind·D1 migration 없음. 원문은 기존 `content`에 섹션 제목과 함께 구성한다. 확정 근거를 수정하면 candidate로 되돌리고 archive revision 증가. 자동 정리 결과만 도착한 상태에서는 원문/확정 여부를 바꾸지 않는다.

`/api/archive/interview`는 기존 워크스페이스 identity·secureMutation·잠금을 사용한다. 다른 브랜드/소유자의 첨부 거부, version 충돌 409, 진행 중 수정 409. 직원도 인터뷰 초안 작성 가능; 확정은 기존 관리자 전용 `review_source`. 자동정리 실행 ID·gateway 주소·근거 스냅샷은 인터뷰 API 응답에서 제외한다. 일반 자료 상세의 원문 접근 권한은 기존 아카이브와 같다.

HERMES 요청이 불확실하면 새 요청을 자동 생성하지 않고 같은 저장 키로 복구한다. 실행 중 연결 주소가 바뀌면 원래 주소 복원 전 조회하지 않는다. 앱을 닫아도 접수된 HERMES 작업은 계속 실행되며 앱 재접속 후 결과를 가져온다(별도 서버 worker의 인터뷰 폴링은 없다).

브랜드 자료 확정 후 캠페인에 들어가는 텍스트 상한·최대 자료 수는 기존 정책을 따른다. 긴 인터뷰의 뒤쪽이 발췌에서 빠질 수 있으므로 캠페인 브리프에서 실제 근거를 확인해야 한다. 이 제한을 입력 축소 레인과 협의 없이 변경하지 않는다.

수용 경로: 질문 입력 → 자료 드롭/녹음 → 저장 → 다시 열기 → (음성 전사) → 자동 정리 → 인용 확인·선택 반영 → 관리자 확정 → 캠페인 초안 작성. 실패 시 원본 보관, 재접속 복구, 권한 없는 확정 거부까지 확인한다.

## 업종별 질문지

공통 8섹션·추가 24질문에 업종별 8질문을 더한다. 음식점/배달, 카페/베이커리, 소매/쇼룸, 온라인 쇼핑몰/D2C, 뷰티/웰니스, 운동, 교육, 숙박/여행/대관, B2B/전문 서비스/SaaS, 가맹 모집, 콘텐츠/팬덤/행사의 11종과 공통/기타를 선택한다. 선택은 인터뷰별로 저장되며 변경해도 답변과 첨부는 유지한다. 기존 인터뷰는 공통으로 표시한다.

업종 질문은 동일한 8섹션의 답변란에 기록한다. 추천 질문에도 업종 관점을 포함한다. HERMES에는 선택한 질문지를 안내로 전달하되 사실·인용 근거로 사용하지 않도록 지시하며 기존 원문 인용 검증을 유지한다. 업종 미입력 API는 기존 선택을 보존하고, 알 수 없는 업종 값은 400이다. 새 환경변수·DB migration 없음.
