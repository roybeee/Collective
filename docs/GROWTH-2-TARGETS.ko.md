# 성장2 사업목표·30일 리뷰

G2-32의 사업목표와 기간별 리뷰 증분이다. 잠정·확정 목표와 변경 이유를 기록하고, 특정 목표 판에 고정한 주문 장부 관측과 다음 행동을 보존한다. 관측 목표 충족은 사업 성공·인과 기여·확대 권한을 뜻하지 않는다.

## 목표 계약

지표는 장부 순매출(`netRevenue`), 유료 주문 수(`paidOrders`), 광고·제작비 배분 후 공헌이익(`contributionProfit`)이다. 절대값만 비교하며 기준선0에서 성장률을 계산하지 않는다. 미확인 금액과0을 구분하고 공헌이익 기준선·목표에는 음수를 허용한다.

잠정/확정 상태, 기준선·목표값, 관측기간·실행 착수일, 분모·집계 기준, 책임자, 자율 범위, 수익 조건, 최대 탐색손실, 필수 개선지표, 중단 조건·기준일, 변경 이유, 미확정 사유·확정 예정일을 기록한다. 빠진 조건은 준비도에 표시한다. 미정 목표 저장이 기존 허용 판매·학습을 막지 않으며 목표 확정은 계정·예산·재고 권한을 부여하지 않는다.

개정은 새 판과 변경 이유를 저장한다. 이전 판과 이미 작성한 리뷰는 남긴다. 새 리뷰는 현재 캠페인의 최신 목표 판을 명시적으로 선택한다.

## 관측과 판정

서버가 목표의 명시적 관측기간으로 같은 소유자·브랜드·캠페인·지점 주문을 집계한다. 클라이언트가 보낸 관측값은 사용하지 않는다. 유료 주문은 결제액이 양수이고 환불 후 잔액이 있는 결제 완료 주문이다. 주문 상태와 결제·환불 잔액이 불일치하면 판단을 보류한다.

현재 값은 주문 장부의 관찰이다. 비용 미확인은0으로 채우지 않으며 마케팅비 차감 전 기여액과 광고·제작비 배분 후 공헌이익을 구분한다. 후자는 비용 배분이 미확인이라 목표 판정도 보류한다. 현금 수령·순현금·은행 대사·인과 기여를 장부 합계로 대신하지 않는다.

- `held`: 목표·기준선·비용·장부 관측 등 필수 근거 부족.
- `interim`: 필요한 관측값은 있지만30일 조건 미충족.
- `observed_met`: 성숙 관측기간의 장부 값이 목표 이상.
- `observed_below`: 성숙 관측기간의 장부 값이 목표 미만.

관측기간 길이, 실행 착수 후 경과, 한국 시간 기준 관측 종료일 경과를 함께 확인한다. 종료일 진행 중에는 최종 기간 판정으로 취급하지 않는다. 목표0의 수학적 충족이나 주문0을 실제 고객 매출 성공으로 표시하지 않는다. `mayExecute=false`, `mayScale=false`, 인과 상태 `not_measured`를 유지한다.

## 불변 리뷰와 명시적 재대조

리뷰는 당시 목표 ID·판·기간, 서버 장부 집계, 선택한 일일 결정 ID·판·제목과 스냅샷 다이제스트를 고정한다. 운영자는 투입 자원·비용 근거, 고객 질문·반품 원인, 대표 예외, 다음 행동, 다음30일 계획을 기록한다. 개인정보와 인증정보는 입력하지 않는다.

리뷰는 수정하지 않으며 정정은 새 리뷰로 남긴다. 목표 개정 시 과거 판임을 표시한다. 일일 결정도 같은 캠페인의 현재 판이어야 한다. “최신 장부와 대조”는 선택한 리뷰1건의 기간으로 현재 집계를 읽어 차이를 표시한다. 정렬한 내부 주문 ID·버전의 해시도 대조하므로 총액이 같아도 원장 개정을 확인할 수 있다. 캠페인 판·지점 변경을 구분하며 양쪽 장부가 관측되지 않았으면 동일하다고 판단하지 않고 비교를 보류한다. 이 조회가 과거 스냅샷·판정을 덮어쓰지 않는다. 전체 리뷰마다 자동 장부 재조회는 하지 않는다.

## 저장과 접근

`/api/growth/targets`의 `save_target`, `capture_review`를 사용한다. 관리자 권한·CSRF·소유자 잠금·캠페인/목표 버전 검사, 같은 UUID/내용의 멱등 처리와 내용 충돌 거부를 적용한다. 목표 투영·추가전용 이력·요청 기록은 원자 저장하고 리뷰는 추가전용이다.

캠페인별 목표100개, 이력1,000개, 리뷰500개, 요청5,000개로 제한한다. 새 kind4종은 캠페인 소속으로 삭제 정책·영향 표시에 등록한다. 보관 캠페인은 조회만 가능하다. 외부 메시지·지출·발주·계약·모델 호출은 수행하지 않는다.

## 검증과 잔여

전용 검사와 브라우저에서 0/null·음수 이익·기간 경계·비용 미확인·유료 주문 정의, 소유자/브랜드 격리·CAS·멱등 충돌·원자 실패, 목표 개정/주문 정정 후 과거 리뷰 보존과 명시적 재대조를 검증한다. 실제 실행 결과는 STATUS와 PR에 기록한다.

광고·제작비 배분 후 공헌이익, 순현금·공식 정산 대사, 재고·실행·반품 원인의 종합 연결, 실제 자율 완료 비율, 성숙 재구매·검증 증분, 다음30일 자원 배치의 실제 실행은 잔여다. G2-32 전체나 성장2 사업 성과의 완료를 뜻하지 않는다.
