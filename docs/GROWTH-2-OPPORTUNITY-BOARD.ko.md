# 고객 기회와 실행 일정

G2-07·25의 기회 연결·순서·일정 부분이다. 현재 성장 기록의 고객 상황, 상품, 구매 이유, 오퍼, 미션을 한곳에서 읽고 해당 기록의 편집기로 이동한다. 신규 외부 수집·수요 예측·집행은 수행하지 않는다.

## 조회 계약

- 기존 성장 조회의 현재 출처·사실·상품·재고·판 준비도를 재사용한다. 새 API나 저장 원장을 만들지 않는다.
- 고객 기회당 한 행을 만들고 여러 오퍼·상품·미션을 연결한다. 누락된 상품이나 구판 참조를 숨기지 않는다.
- 오퍼별 준비/보류를 유지한다. 준비된 오퍼 하나가 기회 전체의 집행 가능성을 뜻하지 않는다.
- 고객 기회 기한을 연결 미션의 기한으로 덮지 않는다. 일정은 기회 ID와 미션 ID마다 한 번만 표시한다.
- 기한순, 같은 기한의 확인 필요 상태, ID순으로 안정 정렬한다. 기한 미확인/비정상은 따로 구분하며 매출이나 수요 예측 점수로 표현하지 않는다.
- 날짜 기한은 한국시간 하루 종료, ISO 기한은 명시 시간대의 실제 시각을 사용한다. 지난 기한·오늘·예정·미확인·비정상을 준비도/실행 상태와 분리한다.
- 기존 활성 미션 정의(staged/unknown)를 유지한다. 초안을 포함한 미종료 수는 별도로 표시한다. failed/observed/cancelled를 성공으로 합치지 않는다.
- 기회와 연결되지 않은 오퍼/미션도 확인 목록에 남긴다.

## 화면 이동과 검증

정확한 기록 ID로 기존 편집기를 연다. 편집 중 미저장 입력이 있으면 보드 이동을 잠그고 저장 또는 변경 취소 후 이동하게 한다. 조회가 실패했을 때 남아 있는 보드는 이전 조회 결과로 표시한다.

순수 테스트는 한국시간 자정·ISO 시간대·잘못된 날짜·동률 정렬·다중 연결 중복·원본 입력 불변·종료 및 결과 불명 상태를 확인한다. 브라우저는 기회에서 실제 오퍼/미션 열기·미저장 입력 보존·오류 시 이전 자료 표시·모바일을 확인한다.

자동 기회 발굴·시즌/팬덤 일정 수집·확정 수요/성과 판단은 잔여이며 원안 전체 완료가 아니다.
