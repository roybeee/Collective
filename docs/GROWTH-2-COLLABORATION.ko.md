# 성장2 크리에이터·파트너 협업

대상 카드: G2-27(크리에이터/제휴의 청중 적합 근거·브리프·권리·조건·수수료·추적 링크·일정). [수요 단계 근거](GROWTH-2-DEMAND-EVIDENCE.ko.md)가 자체 계정 발행만 다루는 것을 보완한다.

- **계획**: 게재 방식이 `creator`/`partner`인 수요 단계의 정확한 시퀀스 판에만 연결한다(자체 게시 단계 거부, 협업 종류 = 단계 게재 방식). 협업자는 가명 별칭 ID로만 기록하며 이메일·전화 등 연락처는 거부한다. 청중 적합 근거, 브리프, 사용 권리 범위·기간(일), 조건, 고정 수수료(원)·성과 수수료율(0~50%), 현재 캠페인·지점의 추적 코드(선택), 납품·게시 기한.
- **단계 영수증**(운영자 확인): 제안 → 합의 → 콘텐츠 납품 → 브랜드 승인 → 게시 확인 → 정산, 정산 전 언제든 취소. 단계를 건너뛸 수 없고 시각은 이전 단계 이후·현재 이전이다. 합의 뒤 계획은 고정된다. 승인은 **광고·협찬 표시**와 **가짜 참여·후기 없음** 확인이 모두 필요하다. 정산은 지급액(또는 미확인)을 남긴다. 합의~게시 단계는 연결한 수요 단계 내용이 바뀌면 막히고 화면에 `held`로 보인다.
- **성과**: 추적 코드가 있고 게시가 확인되면 게시일 이후 해당 코드로 귀속된 지점 주문의 건수·순매출·공헌이익(비용 미확인이면 `null`)을 보여준다. 인과 효과는 `not_measured`.
- **경고**: 고정 수수료 > 단계 계획 비용, 납품·게시 기한 경과, 고정 수수료만인데 지급액 초과, 추적 코드 없음.
- 연락·메시지 발송·지급은 하지 않는다(`mayContact:false`, `mayPay:false`). 실제 계약·지급은 조직 절차로 하고 여기에는 증빙 ID만 남긴다.
