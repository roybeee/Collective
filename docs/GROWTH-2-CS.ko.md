# 성장2 고객 문의·약속 기한

대상 카드: G2-30(구매 후 출고/지연·문의·취소/반품/환불과 반복 원인 처리)의 CS 부분. [반품 원인](GROWTH-2-RETURN-REASONS.ko.md)·[원인 연결](GROWTH-2-CAUSE-LINKS.ko.md)을 보완한다.

- **접수**: 유형(배송 지연·상품 문의·옵션 변경·취소·반품·환불·불량·기타), 경로, **운영자 요약**(고객 원문·이름·연락처·주소·긴 인용문 거부), 선택 주문 품목(현재 캠페인, 판 고정), 접수 시각(현재 이전), 약속 기한(접수 이후), 담당, 우선순위. 응답·해결 뒤에는 접수 내용을 바꾸지 않는다.
- **처리**: 응답 → 해결(해결 방법 필수: 안내·출고·교환·반품·환불·조치 없음·기타), 해결 → 다시 열기, 미해결 → 취소. 처리 시각은 접수·이전 처리 이후, 현재 이전. 모두 운영자 증빙 ID와 함께 추가 전용으로 쌓인다.
- **서비스 수준**: 약속 기한이 지난 미해결은 `overdue`로 목록 맨 위, 기한 뒤 해결은 `resolvedLate`, 첫 응답까지 시간. 만족도·비율이 아니라 운영자가 한 약속 기준이다.
- **반복 유형**: 최근 30일 유형별 문의 수가 3건 이상이면 반복 후보(`ticket_count_not_rate`). 품목이 연결되면 같은 품목의 반품 원인 기록을 함께 보여준다. 품목이 바뀌면 `held`.
- 자동 응답·고객 발송·환불·재고 변경은 하지 않는다(`mayReply:false`, `mayRefund:false`). 보관 캠페인에서도 처리 기록은 계속 남길 수 있다.
