# 성장2 운영 교훈 적용 계보·결과 회수

대상 카드: G2-13(학습 규칙·보상 계보: 운영 교훈을 실제 다음 제작/실행 맥락에 적용하고 효과를 회수)·G2-31(교훈 재사용/퇴역과 성공/실패/무효 구분).

- **적용**: 결정·교훈 화면에서 `reusable`이고 누락·만료가 없는(`canReuse`) 교훈만 적용한다. 대상은 판매 미션·상세페이지 수정안·수요 시퀀스·판매 실험의 **정확한 판**이며, 적용 방법·확인할 결과·효과 확인일과 교훈 digest를 남긴다. 후보·시험·퇴역 교훈, 구판 교훈·대상은 거부한다.
- **제안**: 진행 중 미션마다 아직 적용하지 않은 재사용 교훈을 성공 기록 순으로 보여준다. 제안은 자동 적용이 아니다(`autoApply:false`).
- **결과 회수**: 운영자가 성공·실패·무효(판단 불가)를 증빙과 함께 한 번 기록한다(덮어쓰기 불가, 적용 이후·현재 이전). 확인일이 지난 미회수 적용은 표시한다. 교훈·대상이 개정되면 적용 기록은 `changed`로 보인다.
- **재사용 결과 집계**: 교훈별 적용·성공·실패·무효·대기. 실패 2회 이상이고 성공보다 많으면 “검토 권장”만 표시하며 자동 퇴역·규칙 승격은 하지 않는다(`mayPromote:false`). 인과 판정이 아니다.

저장: `growth_lesson_application`·`_history`·`_request`. 캠페인 삭제 시 보존.
