# 마케팅 스킬 이식 대응표 (P0, 사전 `compliance-lexicon-2026-11-16.16`)

> 비유: 바깥 요리사의 레시피 바인더를 그대로 벽에 붙이지 않고, 우리 카드 양식으로 다시 써서 붙이는 일이다. 카드마다 "어느 판에서 옮겼는지" 도장(커밋·해시)을 찍어, 바인더가 바뀌면 어느 카드를 다시 봐야 하는지 알 수 있게 한다.

- **결론:** 마케팅 스킬(로컬 전용 저장소, 태그 `v1`, 커밋 `a63c6b7`)의 윤리 점검 위험표 중 법령 확인 기록이 있는 위험만 규정 사전의 옵트인 묶음 `mkt`(새 규칙 14개 + 기존 규칙 확장 2개)로 옮겼다. 스위치 `compliance_mkt_rules`는 기본 꺼짐이고, 꺼지면 이슈 목록이 `.15`와 같다.
- **공개 저장소 원칙:** 스킬 문장·예시 카피·브랜드 사실·원문 행 번호는 넣지 않는다. 판단 규칙만 새로 썼다. 법령 근거는 스킬의 법령 확인 기록(2026-11-15 조회) 행만 쓰고, 그 밖은 `미확인`이다. 『카피수업』(B06)만으로 선 규칙은 넣지 않았다.
- **출처 기록:** [`docs/marketing-skills/provenance.json`](marketing-skills/provenance.json)에 커밋, 파일별 sha256, 파일마다 나온 규칙 id와 프롬프트 단위(P4에서 채움)를 적었다.
- **드리프트 검사:** `node scripts/marketing-skills-drift.mjs`. 로컬에 스킬 저장소가 있을 때만 해시를 대조하고, 없으면 건너뛰고 0으로 끝난다(CI·빌드). 바뀐 파일이 있으면 1로 끝나고 다시 볼 규칙 id를 출력한다.
- **법률 자문이 아니다.** 규칙은 사람이 확인할 표현을 찾는 자동 점검이다.

## 3. 같은 저울 재채점

- 사전 버전이 바뀌었으므로 비교에 쓰는 기준 run(품질 기준선, 11-09·11-15 글로벌 평가)은 `regrade_run`으로 다시 채점해야 한다. 운영 재채점은 이 단계에서 하지 않았다(`not_run`). 로컬 측정은 [2026-11-16 관측](observations/2026-11-16-mkt-lexicon.md)에 있다.
- 순서: ① 스위치를 끈 채 재채점해 이슈가 `.15`와 같은지 본다(회귀 오라클). ② 소유자 워크스페이스에서만 스위치를 켜고 다시 재채점해 새로 잡힌 항목에 TP/FP를 붙인다. 켤 후보는 정상 묶음 오탐 0, 실제 적중 정밀도 90% 이상인 규칙만이다.
