# 성장2 M3 — 소재·기존 실험 검수 증분

광고 준비·성과·주문 대조 다음에 소재·실험 검수 화면을 연결한다. 새 실험 원장을 만들지 않고 기존 `execution_creative`, 브랜드 확정 사실, `store_experiment` 또는 `viral_experiment`를 참조한다.

- 소재안은 첫 문장·본문·CTA·영상 대본·사용권 근거·랜딩 검토 메모다. 기존 카피 팩에서 만든 실험의 처치안 문구를 가져올 수 있다. 새로운 모델 호출이나 자동 영상 제작을 주장하지 않는다.
- 미완성 초안을 저장할 수 있다. 검토 기록에는 소재 판/PNG 해시·확정 사실 ID/판·기존 실험 판·준비 계획 판·캠페인 판·행위자/시각을 묶는다. 이 중 하나라도 바뀌거나 근거가 만료되면 유효한 검토로 표시하지 않는다.
- 다른 캠페인 소재/실험, 시작 후 실험, 사용권/랜딩 확인 누락, 미확인 가격·할인율, 근거 없는 후기, 기존 표시·광고 점검의 block은 검토 저장을 거부한다. 원화 표현은 원/천원/만원을 정규화해 정확히 대조하며 숫자 부분 문자열을 근거로 인정하지 않는다.
- 점검기는 모든 거짓 주장이나 법률 위반을 판별하는 시스템이 아니다. 자동 경고/한계를 명시하고 사람이 확인해야 하며 사용권 근거는 운영자 확인 기록이다. 법률 자문·플랫폼 승인으로 표시하지 않는다.
- 초안 저장은 이전 검토를 대체한다. 검토 기록은 광고 생성·활성화·예산 승인으로 사용하지 않는다. 이 API는 외부 요청/광고비 집행을 하지 않는다.

## 검증과 후속

전용 모의 검사 30 assertions: 초안/검토 구분, 명시 확인, 범위 격리, 가격 숫자 부분 일치 거부, 기존 카피 재사용, 가짜 후기·사용권·랜딩 누락, 근거·소재·계획·실험 판 변경, 만료, 역할·CSRF·버전 충돌·보관, 활성화 거부. 신규 E2E는 모바일·데스크톱 미완성 초안 보존·재조회·근거 미확인 검토 거부를 확인한다.

기존 소재와 실험의 실제 준비가 필요하다. 광고 객체 PAUSED 생성/재조회·쓰기 권한, 승인 예산·중단, Pixel/CAPI와 실제 몰 연결, 순이익/증분 효과 보고는 후속이다. 기존 AI 생성물 표시/승인 스위치를 켜거나 우회하지 않는다. 외부 제출 전에 해당 출처·표시·규제 게이트를 다시 확인해야 한다.
