## 변경

대표의 베타 UI/UX 개선 지시에 따라 긴 입력·누락·내부 개발 상태 목록을 네 단계로 재구성했다. 판매 목표 → 상품과 수익 → 예산과 일정 → 준비 점검으로 이동하며 작성 내용을 유지한다. 경로 선택 카드, 단계별 확인 수, 다음 할 일, 실시간 기여이익·광고비 회수 구매 수와 저장 상태를 표시한다. 모바일은 한 열로 배치한다.
