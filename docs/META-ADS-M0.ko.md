# 성장2 Meta 광고 M0 — 판매 준비 계획

기준 main `9ac45ed`. 대표의 2026-09-28 개발 진행 지시에 따른 첫 제품 증분이다. M0 전체 외부 계약 확정이나 M1~M6 구현 완료를 뜻하지 않는다.

## 구현

캠페인 상세 → **Meta 광고 준비**에서 자사몰/콘텐츠 경로, 구매/문의/인지 목표, 상품·전환 목적지·시스템·계정 별칭, 가격·원가·변동비, 총예산·일 목표·손실 한도·안전 여유·기간·중단 기준을 저장한다. KRW 정수와 Asia/Seoul을 첫 지원 범위로 제한한다. 외부 자격증명은 받지 않는다.

- `GET /api/meta-ads?campaignId=...`: 로그인한 워크스페이스 역할이 해당 캠페인의 저장 계획·준비도·참조를 읽는다. 직원은 읽기만 가능하다.
- `POST /api/meta-ads`, `action=save_plan`: 대표·관리자, 동일 출처, 기존 워크스페이스 쓰기 잠금. `expectedVersion`과 `campaignVersion`이 둘 다 일치해야 저장한다. 그 외 행동(activate 포함)은 400이다.
- `meta_ads_plan`: 캠페인당 최신 계획 1행, parent=campaignId. 서버가 브랜드·캠페인·작성자·판을 정한다. 성공한 저장과 캠페인 이력을 D1 batch로 묶는다. 캠페인 삭제 때 계획도 지우고 삭제 영향 화면에 이름을 표시한다.
- 기존 캠페인의 brandId·storeId·storeExperimentId와 `store_order` 원장을 참조한다. 주문·실험을 복제하지 않는다. 몰 주문·Meta 계정의 검증된 매핑은 M1/M2 후속이다.
- 누락·종료된 기간·바뀐 캠페인을 준비도에 표시한다. 원가/변동비 미확인은 이익 null이며 0으로 처리하지 않는다. 인지/문의는 매출 미검증이다.
- 준비 체크는 운영자의 선언이다. 완료 표시도 **계획 입력 완료·외부 검증 대기**다. 읽기/외부 초안/활성화/전환 전송 가능 여부는 모두 false이며 외부 요청·모델 요청·주기 작업·광고 지출은 없다. 로컬 계획 기능은 로그인 후 이용 가능하다. 이후 외부 어댑터의 기본 꺼짐 플래그와 별도 집행 승인 계약을 대체하지 않는다.
- 입력 URL은 HTTPS, 자격증명·쿼리·조각 없이 저장한다. 해당 URL을 서버가 가져오지 않는다. 고객 정보·비밀값을 자유 입력란에 쓰지 않도록 안내한다. 모델 입력·외부 전송은 없다. 감사에는 계획 판·행위자만, 상품·비용 원문은 쓰지 않는다.
