# 성장2 실험 관측·판정·규칙

기존 사전등록을 참조해 시작 전에 통계 설계를 고정한다. `실험 관측` 탭의 소유자 흐름은 설계 → 방문자 배정 → 단위별 관측/정정 → 성숙 결과 → 규칙 제안 → 별도 승인이다. 외부 광고를 생성하거나 집행 권한을 부여하지 않는다.

## 불변 계약과 관측

- 사전등록 기간·성숙 대기·지표·군별 최소 표본·소재 ID/판/해시를 복사한다. 의미 있는 최소 차이, 단위별 최솟값/최댓값, 비식별 방문자 단위, 순세액 명시 기준을 시작 전에 고정한다. 같은 등록의 설계를 뒤늦게 바꾸지 못한다.
- 서버가 비공개 난수 seed와 몰이 발급한 비식별 방문자 키의 SHA256으로 1:1 무작위 배정한다. 같은 키는 같은 군을 유지한다. 이메일·전화번호 원문은 받지 않는다. 실제 몰에서 동일 방문자 키를 유지하고 배정한 안을 노출하는 운영 연결은 별도 인수 조건이다.
- 운영자가 노출·완전 추적·오염 여부, 미구매자를 포함한 단위별 주문 참조, 실제 결제 시각과 원장 증빙, 비용·광고비·제작비 배분·순세액을 기록한다. 이 입력은 운영자의 증빙 확인이며 외부에서 독립 검증한 데이터라고 표시하지 않는다.
- 주문은 동일 지점·캠페인 원장만 연결한다. 한 주문을 여러 단위에 연결할 수 없다. 실제 결제 시각은 `max(실험 시작, 서버 배정 시각)` 이후·실험 종료 이전이어야 하며 장부의 한국 날짜와 일치해야 한다. 날짜만 있는 자료는 구매 성과로 인정하지 않는다.
- 관측 판은 CAS와 소유자 잠금으로 갱신하고, 모든 관측 정정본을 추가 전용 원장에 보존한다. 요청은 소유자당 분당 60회, 실험당 최대 10,000단위, 단위당 최대 100주문이다.

## 계산과 판정

- 구매 지표는 **주문 건수**가 아닌 배정 방문자 중 순결제 구매가 있는 비율(0/1)이다. 중복 주문과 미구매자를 누락하지 않는다.
- 기여이익은 배정 단위의 현재 결제−환불−장부 변동비−명시 순세액−배분 광고비−제작비다. 미구매자는 매출 0이며 배분 비용을 반영한다. 원가 미확인, 추적 누락, 조건 오염, 등록 범위 밖 값은 `invalid`; 범위 밖 값을 임의로 잘라내지 않는다.
- `not_started/collecting/maturing/insufficient/invalid/inconclusive/supported/rejected`를 구분한다. 관측 종료+성숙 대기 전에는 확정 계산을 저장하지 않는다. 소재·캠페인 설계 변경과 정상적인 주문·환불 증가를 분리한다.
- 방법은 bounded Hoeffding 양측 구간과 양 군 union bound다. k번째 결과 판에 `alpha=0.05/(k*(k+1))`를 사용한다. 전체 판의 오류 허용치 합은 0.05 이하이며, 정정 때마다 같은 5% 검정을 반복하지 않는다. 반경은 `(upper-lower)*sqrt(log(4/alpha)/(2*n))`; 차이 구간이 등록 최소 개선폭보다 위이면 supported, 음의 최소폭보다 아래이면 rejected, 나머지는 inconclusive다.
- 동일 원자료 digest에는 같은 결과를 반환하며 불필요한 새 판을 만들지 않는다. 지연 환불/관측 정정은 원자료 digest와 결과 판을 새로 남기고 이전 결과는 보존한다. 결과는 독립적인 배정 단위·실제 무작위 노출·완전 추적 등 전제가 맞을 때의 조건부 근거다. 운영자 입력만으로 인과 효과가 입증되었다고 주장하지 않는다.

근거: [CMU 통계 강의의 bounded-variable Hoeffding 부등식](https://www.stat.cmu.edu/~cshalizi/sml/21/lectures/06/lecture-06.html). 두 군 및 정정 판의 union bound 배분은 COLLECTIVE의 보수적 설계다. 기존 바이럴 공유/완주/클릭 통계에 구매·연속 이익을 강제 변환하지 않는다.

## 규칙 계보

성숙한 supported/rejected 최신 결과에서 규칙 초안을 제안한다. 소유자가 원자료를 다시 확인해 승인해야 `learning_rule(origin=meta, grade=performance_observed)`로 30일 적용된다. 적용 지점·브랜드·Instagram 채널을 제한하며 광고비 승인과 무관하다. 모델에 전달할 때마다 원자료를 재대조하므로 환불·정정 이후의 낡은 규칙은 새 판정을 저장하기 전에도 제외된다. 기존 학습 화면에서 중지·종료할 수 있고 재검증은 Meta 사전등록에서 한다.
