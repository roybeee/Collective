# 성장2 M6 보고 기반 증분

M1 수집 스냅샷과 M2 기존 주문 장부를 같은 기간으로 대조한다. M4·M5의 실광고 생성/제한 집행이나 증분 실험 종료를 기다려야 하는 효과 검증과 구분한 보고 기반이다. 전체 M6 종료로 표시하지 않는다.

- Meta 보고 구매 금액·광고비·ROAS: 저장된 단일 성과 스냅샷이 조회 기간 전체를 포함할 때만 집계한다. 누락 전환은 null, 누락 기간은 0으로 메우지 않는다. 수동 입력/API, 계정·캠페인, 전환 인정 기간, 수집 시각을 보존한다.
- 장부 순매출: 같은 브랜드의 연결 지점(지점 없는 브랜드 캠페인은 브랜드 지점 전체)의 주문일 기준 결제액−환불액이다. 전체 채널 합계이며 전체 매출의 완전성을 주장하지 않는다. 취소·전액 환불은 유효 주문 수에서 제외한다.
- 캠페인 귀속: 기존 campaignAttribution 집계와 게시 관문을 재사용한다. 추적 코드·수동 귀속을 포함하므로 Meta 귀속과 다르다. 다른 브랜드/지점 주문은 제외한다.
- 원가 미입력은 공헌이익 미확인으로 유지한다. 공헌이익은 광고·제작·고정비 차감 전이다. 부가세 기준 미대조, 순이익·증분 매출은 미확인이다. 임의 순이익·자동 확대·학습 규칙 승격은 없다.
- Meta 수집 뒤 24시간 경과, 캠페인 판 변경, 미성숙 전환 인정 기간, 당일 미완료를 경고한다. 인정 기간 경과는 마지막 날짜 KST 종료+1일/7일 뒤 수집했는지의 보수적 표시이며 플랫폼 확정 보증이 아니다.
- 관리자 명시 확인 후 집계 시점을 meta_ads_report에 불변 기록한다. 확인한 근거 digest와 보고 판을 서버 재집계와 대조한다. 같은 근거는 중복 기록하지 않는다. 이후 환불/정정이 생기면 이전 수치와 변화량을 표시하며 이전 보고는 바꾸지 않는다.
- JSON 내려받기는 집계와 정의만 포함한다. 원본 주문 번호·메모·연락처를 복사하지 않는다. 최근 20개 이력을 조회한다. 기록은 캠페인 삭제 정책에 따라 삭제된다.

## 검사와 후속

전용 모의 30 assertions: 인증/소유자·브랜드·지점 격리, 환불, 미확인 원가/전환, 자료 기간 부분 포함, 실제/보고 금액 분리, 귀속 재사용, 변경 감지와 불변 이력, 중복·CAS·보관·CSRF·직원 거부, 원본 주문 필드 미노출. 모바일·데스크톱 E2E는 기간 변경, 명시 확인, 기록과 재조회를 검사한다.

실제 광고 집행, 실몰 완전성 대조, 부가세/비용 계약, 고객 전환 동의, 대조군 설계·성숙 표본·실험 판정은 후속이다. 해당 근거 없이 광고가 이익을 만들었다고 표시하지 않는다. 외부 전송·새 모델 호출 0.
