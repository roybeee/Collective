# 성장2 Meta 제한 판매 트랙 개발 종료 판정

**Meta M0~M6 필수 개발 종료 passed · 게시/runtime-verified 완료 · 운영 인수 blocked · 효과 검증 not_run.** [최종 릴리스](releases/2026-09-29-dabf656.md). 이 판정은 성장2 원안 전체의 완료를 뜻하지 않는다. 원안 v2.0의 G2-00~32 진행은 [전체 개발계획](GROWTH-2-PLAN.ko.md)에서 추적한다.

범위: 대표의 “성장2 남은 개발 완료하라”, 첫 몰 `mapdal.kr`. M0~M6 중 자사몰 구매·정적 이미지·KRW/서울·한 광고 구성의 제한 실험 경로다. 자동 영상 제작, 다계정·다통화·대규모 자동 확대는 필수 범위가 아니다.

## 운영 경계

- 모든 외부 쓰기 플래그는 기본 OFF다. 이번 개발 검증에서 실제 Meta 요청·고객 전환 전송·광고비 집행은 하지 않았다.
- CAPI는 별도 목적·필드 동의, dataset/토큰, 실제 구매 시각과 브라우저 정보, 개인정보 없는 구매 URL이 필요하다. 과거 Meta 수신의 취소는 로컬 철회와 별개다.
- 광고 예산 단위는 자유문구가 아닌 공식 SDK Currency 모델의 런타임 `user_currency/currency_offset`와 광고계정 KRW로 대조한다. 해당 응답/권한이 없으면 활성화는 차단한다. 정지에는 이 새 활성화 조건을 요구하지 않는다.
- Meta 집계 지연, 광고비 청구 지연, 네트워크/워커 중단 때문에 로컬 한도는 공급자의 청구 상한을 보장하지 않는다. 최종 PAUSED 확인 및 청구액 대조 후에만 예산을 해제한다. 손실 한도는 매출을 가정하지 않고 지출액으로 보수적으로 중단한다.
- 실험 관측·노출·순세액/비용 배분은 증빙을 확인한 운영자 입력이다. 실제 무작위 노출·동일 방문자 식별·완전 추적을 입증하지 않고 인과 효과를 주장하지 않는다. 통계 계산 통과는 수익 달성 검증이 아니다.
- 기존 의존성 감사: Critical 0 / High 2 / Moderate 1 / Low 1. browserslist·baseline-browser-mapping·Babel의 기존 잠금파일 항목이며 이번 변경은 패키지를 수정하지 않았다. 별도 의존성 패치 작업으로 관리한다.

## 검증·게시 상태

로컬 전체 227/227 suites·14,123 assertions, 브라우저104 및 최종 핵심8, 이메일 인증1, 타입·빌드·프롬프트22·lint 기준선70/39, Python 워커13·설치70·맵달19 passed. 새 비즈니스 모듈10개 V8 함수 커버리지141/151(93.4%), 문장/분기 지표는 별도 측정하지 않았다.
