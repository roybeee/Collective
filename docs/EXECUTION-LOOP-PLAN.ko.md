# 실행 연결 첫 단계 — 승인된 개발 범위

기준 main: d96a6ca. 사용자 승인: “좋아 그렇게 개발 진행하자.”

1. 브랜드·지점 사실 원장: 미확정/확인/제외, 출처·검증일·만료·버전·이력. 사람만 확정하며 역할 입력에도 전달.
2. 실제 정사각 PNG 정보 카드: 확정 사실을 선택해 템플릿 제작, 파일 저장·다운로드, 파일 해시와 캠페인/사실 버전 기록. 생성형 이미지·영상 전체를 포함하지 않는다.
3. 실행 통제: 소재/계정/예약 시각/사실 버전/예정 비용을 묶어 명시 승인. 게시 접수 전 횟수·예정 비용 예약, 중복 제출 금지, 접수 불확실은 재전송 금지. 기존 LLM 전체와 외부 서비스의 실제 청구 상한을 보장하는 기능은 아니다.
4. 첫 발행 어댑터: Buffer Instagram. 실제 계정 검증·암호화 자격증명·예약 접수·외부 상태 재조회. 공개 이미지 호스트와 연결 계정이 없으면 blocked로 표시하고 운영 게시하지 않는다. 비공개 Sites 파일 URL을 공개 URL로 간주하지 않는다.
5. 기존 주문장부 확장: 캠페인·소재 귀속과 근거, 잘못된 지점/브랜드 연결 차단. 연결 주문은 순증 주문과 구분.

실행 흐름: 사실 확정 → 카드 저장/다운로드 → 공개 이미지 연결 → 계정·예약·비용 승인 → Buffer 접수 → 상태 조회 → 주문 연결.

검증: 신규 회귀 RED→GREEN, 실제 SQLite/모의 외부 API, 타입·lint기준선·빌드·브라우저 E2E. 사용자 계정/호스트로 수행하는 real 발행은 별도 증거로 기록. 운영 데이터 자동 수정과 SNS 발행은 개발 완료의 대체 증거로 사용하지 않는다.
