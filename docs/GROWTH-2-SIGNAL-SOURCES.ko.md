# 확정 시장자료를 성장 신호에 연결

원안 G2-06의 기존 자료 재사용과 출처 신선도 부분이다. 확정된 시장 아카이브를 캠페인의 시장 근거로 가져오고, 원자료의 변경·제외가 이후 판단에 전파되게 한다. 새 외부 수집이나 수요 검증을 수행하지 않는다.

## 입력과 저장

- 현재 브랜드에 속한 market 자료만 조회한다. 지점 자료는 캠페인의 지점과 같아야 한다.
- confirmed 상태·공개 HTTPS URL·관측 시각·요약을 기존 시장 신호 검증기로 다시 확인한다. 쿼리·인증정보·내부 주소를 제거해 강제로 통과시키지 않는다.
- 연구에서 생성된 자료는 완료된 연구와 동일 범위의 실제 원문 접근 근거를 추가 확인한다. 검색 미리보기만 있거나 실패/진행 중인 연구는 보류한다.
- 서버가 제목·출처·관측 시각·내용을 만든다. 가져온 시각으로 관측 시각을 갱신하지 않으며 표본 수는 미확인이다. 긴 원문을 임의로 요약하지 않는다.
- 관리자 요청의 캠페인/자료 판과 UUID를 확인하고 신호·추가 전용 이력·멱등 영수증을 원자 저장한다. 같은 자료의 같은 판은 중복 생성하지 않는다.

## 이후 변경

- 신호에 출처 ID·판·digest를 보존하고 현재 원본과 대조한다. 원본 수정·제외·삭제·범위 변경·조회 실패·만료를 정상 근거로 취급하지 않는다.
- 보류가 고객 기회·오퍼·미션 및 해당 출처 계보를 쓰는 학습 판단으로 전파된다. 기존 실패 미션에서 배우는 경로 전체를 재고 상태 때문에 막지 않는다.
- 가져온 신호를 수동 수정해 출처 계보를 지울 수 없다. 새 원본 판은 다시 검토해 가져온다.
- 조회 후보는 검증된 제목/URL/요약과 보류 사유만 공개한다. 파일 키·자격증명·공급자 오류·모델 응답 원문은 반환하지 않는다.

## 범위와 검증

UI는 시장 근거 단계에 후보·관측 시각·기한·중복/보류를 표시하고 성공 후 기존 신호 목록을 갱신한다. 저장 실패나 응답 유실은 입력과 같은 요청 ID를 보존한다.

검증 대상은 외부 브랜드/지점, 구판·제외·실패 연구, 관측 시각 보존, 중복, 개인정보, 원본 변경의 하위 전파와 수동 수정 우회다. 실제 수집·모델 호출·아카이브 수정은 수행하지 않는다. 전체 원안 완료 판정은 아니다.
