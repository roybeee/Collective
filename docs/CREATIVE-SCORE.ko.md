# 소재 예측 점수(G2) — 추정 · 규칙 기반 · 성과 보장 아님

기준: `docs/GLOBAL-PLAN.ko.md` 에픽 G2. 코드 정본: `lib/creative-score.ts`(순수 점수), `lib/creative-calibration.ts`(순수 보정표), `lib/creative-score-server.ts`(저장·API), `app/api/creative-score/route.ts`, `components/app/creative-score-card.tsx`. 기능 스위치 `creative_score`(기본 꺼짐). 레코드 kind `creative_score`(캠페인과 함께 삭제), `creative_calibration`(브랜드 범위, 캠페인과 무관).

## 1. 무엇인가

작업물(소재 본문·캡션)이 저장될 때 결정론 규칙으로 0~100점을 매기고 구성 요소별 근거를 남긴다. 모델 호출·난수·시계가 없어 같은 입력은 항상 같은 점수다. 점수는 **추정**이며 라벨 `추정 · 규칙 기반 · 성과 보장 아님`을 항상 함께 보인다. 등급은 `낮음`(0~39) · `보통`(40~69) · `높음`(70~100)이다.

### 무엇이 아닌가
- 승인·품질 판정이 아니다. 작업물 상태·캠페인 상태·품질 검수 판정을 바꾸지 않는다.
- 성과 예측 모형이 아니다. 과거 관측과의 상관을 사후 보정표로만 보이며 인과를 주장하지 않는다(`docs/VIRAL-STATS.ko.md` "귀속 ≠ 증분", `docs/EVAL.ko.md` 통계 입장).
- 규제 판정이 아니다. 규제 점검 구성 요소는 `lib/graders/compliance.ts`의 자동 점검 결과를 그대로 쓰며 법률 자문이 아니다.
- 가중치를 스스로 배우지 않는다. 보정표는 등급 표시만 바꾸고 구성 요소 점수·가중치는 코드 상수다.

### 채널 형식 한도(운영 기준, 공식 수치 아님)

| 채널 | 글자 한도 | 해시태그 권장 | 본문 링크 |
|---|---|---|---|
| Instagram · TikTok | 2,200 | 3~8 | 눌리지 않음(0점, 프로필·스토리 링크 권장) |
| YouTube | 5,000 | 0~15 | 가능 |
| 블로그 | 20,000 | 0~30 | 가능 |
| 당근 | 2,000 | 0~5 | 가능 |
| 그 밖 | 5,000 | 0~30 | 가능 |

채널은 캠페인 `channels` 문구에서 첫 번째로 맞는 채널 레지스트리(`lib/channels.ts`) 이름이다(`primaryChannel`). 맞는 것이 없으면 첫 토큰(없으면 `기타`).

### 학습 규칙 판정 표현
규칙은 id·지침·방향(`test`·`caution`)만 받는다. 판정 표현은 지침 안의 따옴표 구절(‘…’ “…” '…' "…" 「…」, 2~40자) 또는 `terms`다. `test` 규칙은 표현이 본문에 있으면 충족, 없으면 미충족이다. `caution` 규칙은 표현이 없으면 충족, 있으면 위반이다. 적용 범위는 `lib/learning.ts ruleApplies`와 같다(같은 브랜드·채널 별칭·지점·역할).

## 3. 저장·실행

- 레코드 `creative_score` id `<작업물 id>:<버전>`, parent 캠페인. 본문·출처·채널·확정/거절 사실·확정 말투·적용 규칙(id@버전)·규제 사전 버전·보정표 버전·최근 게시물 본문을 묶은 SHA-256 `inputHash`가 같으면 다시 쓰지 않는다(멱등). 규칙·사전·보정표가 바뀌면 같은 판이 새로 계산된다(`rulesVersion`).
- 자동 실행: 스위치 `creative_score`가 켜져 있을 때만 온라인 채점 경로 `lib/online-grading.ts gradeSavedArtifacts`(역할 실행 저장 뒤, 잠금 밖)가 `scoreSavedArtifacts`를 부른다. 꺼져 있으면 스위치 1행만 읽고 작업물을 읽지 않는다. 어떤 예외도 던지지 않고 로그 `creative_score_error` 1줄만 남긴다. 회의가 저장한 작업물(`gradeMeetingArtifacts`)과 사람이 고친 판은 자동 계산하지 않는다 — 다시 계산 API를 쓴다.
- 입력: 확정 사실은 `scopedBrandFacts`(지점 사실 우선), 말투는 `brand_voice.confirmedVoice`, 규제 점검은 `checkCompliance(본문,{facts})`, 최근 게시물은 같은 브랜드 캠페인의 발행(`execution_publication`) 캡션 최신 10건(없으면 같은 캠페인·같은 역할의 승인 작업물).
- API `GET /api/creative-score?artifactId=`: 로그인한 모든 역할. `{enabled, artifactId, artifactVersion, score|null}`. 다른 소유자·없는 작업물 404. `GET ?brandId=&channel=`: 보정표(없으면 null).
- API `POST {action:'recompute', artifactId}`: 대표·관리자(직원 403, 비로그인 401, 다른 출처 403). 스위치 꺼짐 409. 같은 입력이면 `written:false`.
- API `POST {action:'calibrate', brandId, channel, observations:[{artifactId, publishedAt, impressions, clicks}]}`: 대표·관리자. 4절 참고.

## 4. 사후 보정 절차

1. 게시 뒤 **7일 이상** 지나고 **노출 30회 이상**인 소재의 관측(작업물 id·게시 시각·노출·클릭)을 모은다. 이 판은 자동 수집 연결이 없다 — 대표·관리자가 Instagram 인사이트·Meta 보고서 값을 `calibrate`로 넘긴다(클릭 ≤ 노출, 정수, ISO 시각, 1~2,000건).
2. 서버가 관측을 저장된 점수(그 작업물의 가장 최근 판)와 합친다. 점수가 없는 작업물은 `missing`으로 돌려주고 뺀다.
3. `buildCalibration`이 브랜드×채널 표를 만든다(`creative_calibration` id `<브랜드>:<채널>`, parent 브랜드).
   - 관측 10건 미만: `insufficient`(표 없음, 점수에 아무 영향 없음).
   - 10~29건: `directional`, 라벨 `방향성(표본 부족)`. 점수의 등급은 바꾸지 않고 `sample{n, 기간}`과 주의 표시만 더한다.
   - 30건 이상: `usable`. 점수 3분위 구간(`bins`: from·to·n·관측 CTR 중앙값)이 **단조**이면 점수가 속한 구간의 관측 순위로 등급을 정한다(하위 구간 낮음·상위 구간 높음). 비단조이면 등급을 바꾸지 않고 "비단조(등급 미적용)"로 적는다.
   - 함께 적는 것: 예측 등급과 실현 3분위의 일치율(`agreement`, 효과 크기가 아님), 구성 요소별 공분산 부호(`components[].sign` + · − · 0, 크기·유의성 없음), 제외 건수(최근·노출 부족·형식 오류), 기간(첫·마지막 게시일), 한계 문장.
4. 표가 생기면 이후 계산되는 점수의 `rulesVersion`에 표 버전·시각이 들어가 같은 판이 다시 계산된다. 표를 지우거나 다시 만들면 또 바뀐다.

표가 하는 일은 등급 표시와 표본 표시까지다. 가중치 자동 학습·규칙 자동 승격은 없다.

## 5. 알려진 편향과 한계

- **길이·형식 편향**: 짧은 질문형 첫 문장과 숫자를 일률적으로 좋게 본다. 브랜드·장르에 따라 긴 서술형이 더 잘 읽힐 수 있다.
- **어휘 사전 의존**: 행동 유도·혜택·장소·시간은 한국어 정규식 사전이다. 사전에 없는 표현(방언·신조어·영문 CTA)은 놓치고, 사전에 든 글자가 다른 뜻으로 쓰여도 센다(예: '점'·'로'가 든 일반 단어는 장소로 세지 않도록 좁혔지만 완전하지 않다).
- **학습 규칙 판정 표현 의존**: 따옴표 구절이 없는 지침은 판정하지 못한다("확인 불가"). 표현이 있어도 문맥(부정·인용)은 보지 않는다.
- **유사도는 토큰 집합 Jaccard**: 어순·의미를 보지 않는다. 짧은 글은 유사도가 낮게, 긴 템플릿 글은 높게 나온다.
- **CTR 하나로 보정**: 저장·공유·주문은 보정에 쓰지 않는다. 노출이 적은 소재는 CTR 분산이 커서 30회 하한도 작다.
- **표본 선택 편향**: 보정 관측은 게시된 소재만 담는다. 게시되지 않은(낮은 점수의) 소재는 관측이 없어 표가 상단으로 치우칠 수 있다.
- **채널 한도는 운영 기준**: 플랫폼 공식 한도가 바뀌어도 자동으로 따라가지 않는다. 표를 고치면 `CREATIVE_SCORE_VERSION`을 올린다.
- 모든 수치는 `mocked` 합성 문안으로 회귀했고 실제 성과와 대조한 `real` 검증은 없다(2026-11-09 기준).
