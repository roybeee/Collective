## 5. 실행 규칙

- 한 에픽 = 한 브랜치(`lane-x/*`, `lane-c/*`, `lane-g/*`) = 한 PR, base `origin/main`. 워크트리에서 작업하고 `node_modules`는 본 저장소에서 심볼릭 링크한다.
- 검증은 `node node_modules/typescript/bin/tsc --noEmit`, `node scripts/test.mjs`, `node scripts/lint-gate.mjs`, `node scripts/run-framework.mjs build`, 해당 E2E. PR 본문에 기준 SHA·명령·결과 수를 적는다.
- 외부 쓰기는 플래그 기본 꺼짐, idempotency key, 결과 불명은 `unknown`으로 기록한다. 실제 외부 호출은 mocked와 real을 구분해 기록한다.
- STATUS.md 레인 X·C·G 칸은 병합 담당(이 세션)이 묶음마다 갱신한다. 게시는 레인 A가 묶음으로 한다.
