  - 예약 판매 시작·발매일·발매 뒤 첫 주로 기간을 나눈다.

적용 대상 권고: 지금 합성 평가 명세(`scripts/eval/specs`)에는 이 단위를 켜는 케이스가 없다. 채널 문구에 올리브영·무신사·커머스가 들어간 캠페인이 없다. 적용 케이스가 0건이면 쌍 평가의 두 쪽 입력이 같아 판정 근거가 되지 않는다. 레인 Q가 dev·봉인 세트에 다음 두 케이스를 더한 뒤 쌍 평가하기를 권한다.

- 화장품 판매처 캠페인: 업종 beauty, 채널 문구에 해당 판매처 이름.
- 팬덤 상품 캠페인: 업종 kpop, 채널 문구에 '커머스'.

한계: K-POP 캠페인은 보통 채널을 '자사몰'·'팬덤 플랫폼'으로 적는다. 이 문구는 지금 적용 조건에 걸리지 않아 후보를 활성화해도 반영되지 않는다. 적용 조건을 넓히는 일은 코드 PR과 묶음 게시, 기준선 재캡처가 필요하다. 이 PR의 범위가 아니므로 후속 제안으로 남긴다.

### 감사 묶음 — `channel.shortform`(Advantage+ 소재 대조)·`viral.discovery`(국내 사례 우선)

`channel.shortform`: 메타 유료 광고 계획일 때만 다음을 적는다.

- Advantage+ 크리에이티브 자동 변경(문구 변형·이미지 보정·음악 추가·비율 변경 등)은 켤 항목과 끌 항목을 사람이 정한다.
- 켠 소재는 게재 직후 광고 미리보기·실제 게재 소재를 승인본과 대조한다. 점검에는 담당자·시점과 확인 항목(문구·가격 표기·효능 표현·로고·자막 가림·광고 표시)을 붙인다.
- 승인본과 다르면 그 자동 변경을 끄고 다시 검수한다.
- 자동으로 만든 문구·이미지도 같은 사실·표시 기준으로 본다.
- 성과는 켬/끔 소재를 나눠 기록하고, 차이를 자동 변경의 효과로 단정하지 않는다.

본문은 '광고 집행' 같은 외부 행동 표지를 쓰지 않는다(코드 소유 거부 규칙).

`viral.discovery`는 다음을 더했다.

- 발견: 국내 계정의 한국어 사례를 먼저 고른다. 해외 사례는 비교가 모자랄 때만 더하고 `observations` 첫머리에 `[해외 사례·보조]`로 표시한다.
- 분석: 해외 사례면 `context`에 그 사실을 적고, 국내로 옮길 때 달라질 조건을 `unknowns`에 남긴다. 국내·해외 성과 수치를 같은 기준으로 비교하지 않는다.

| dev 평가 상황 | 기대 결과 | 실패 사례 |
|---|---|---|
| 메타 유료 광고가 든 계획 | 자동 변경 켬/끔 결정, 게재 뒤 대조 점검(담당·시점·항목) | 자동 변경 소재를 검수 없이 운영, 켬/끔 성과 차이를 효과로 단정 |
| 유료 광고가 없는 숏폼 계획 | 기존 숏폼 지시만 적용 | 이 점검을 설명하거나 해당 없음을 나열 |
| 바이럴 발견(운영, 쌍 평가 불가) | 국내 사례 우선, 해외는 보조 표시 | 해외 사례만 반환, 국내·해외 조회수 직접 비교 |

적용 대상 권고: `channel.shortform`은 합성 명세 대부분(Instagram 채널)에 이미 켜진다. 그 케이스들은 예산이 미정(`null`)이라 유료 광고 줄이 드물 수 있다. 확정 예산이 있고 메타 유료 광고를 쓰는 케이스를 하나 더하기를 권한다. 적용 범위가 넓어 회귀 범위도 넓으므로 `input_budget`과 `industry_metric_leak`를 먼저 본다.

활성화 경로의 막힘: `viral.discovery`는 역할 평가 케이스로 쌍 평가할 수 없어 F3b 게이트로 활성화할 수 없다(`lib/prompt-registry.ts` `pairPrompts`, `PROMPT-REGISTRY.ko.md` '남은 한계').

- 이 후보는 등록까지만 가능하다.
- 활성화하려면 바이럴 작업용 평가 경로(레인 Q 코드)나 대표 결정이 필요하다.
- 대안으로 같은 지시를 `role.insight` 방법에 넣는 안이 있다. 모든 캠페인에 붙고 웹 도구 호출(`input_budget`) 위험이 있어 이번에는 하지 않았다.
