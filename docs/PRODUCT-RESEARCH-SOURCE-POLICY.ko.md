# 상품 리서치 출처 사용 보류와 보존 현황

2026-10-05. 구현 정책판: `md-policy-2026-10-05`.

## 적용 범위

YouTube, 네이버 검색광고 키워드, 네이버 쇼핑 검색은 상품 선정·교차 출처 점수화·AI 메모용 사용 근거가 확정되지 않아 상품 리서치에서 보류한다. API 키 발급이나 인증 성공은 해당 목적의 사용 허락을 뜻하지 않는다. 광고 운영용 네이버 광고 연결은 별도 기능이다.

- 새 연결과 직접 수집, 기존 대기 작업은 공급자 호출·쿼터 차감 전에 검사한다.
- 저장된 점수는 모든 인용 원본이 허용되어야 표시·승인·캠페인 전달할 수 있다. 원본 누락, 알 수 없는 출처, 잘못된 시각, 미래 수집 시각은 보류한다.
- AI 메모와 대기 중 AI 작업은 현재 상품뿐 아니라 작성 당시 점수표와 인용 원본도 재검사한다.
- 과거 백테스트·보정·가중치 제안은 정책판을 확인하며, 새 계산에는 보류 출처를 넣지 않는다.
- 성장 신호가 보류되면 응답에서 복사된 제목·요약·주소·표본 수를 숨긴다. 원본 DB 행을 수정하지 않는다.
- 키워드 묶음은 정책판과 원본 계보를 확인한다. 확인되지 않은 기존 묶음을 DataLab으로 다시 전송하지 않는다.

DataLab·수동 파일·자체 판매 자료에 대한 기존 동작의 유지는 법무 승인 표시가 아니다. 과거 복사본에 원본 계보가 없으면 출처를 소급 확정할 수 없다.

## 보존 현황

소유자는 출처 화면의 **보존 상태 확인**으로 기록 종류별 건수, YouTube 관련 건수, 30일 이상 경과 건수, 수집 시각 확인 필요 건수를 조회할 수 있다. 두 기능 스위치가 꺼져 있어도 API 조회는 가능하다. 응답에 원문·API 키·개별 기록 ID를 포함하지 않는다.

조회는 원본·점수·메모·대기 작업·성장 신호·소싱 후보·오퍼·이력과 확인 가능한 참조 계보를 포함한다. 행·바이트·계보 탐색 한도, 손상된 기록, 누락된 원본 참조가 있으면 `complete:false`다. `complete:true`도 외부 시스템에 남은 복사본의 삭제를 증명하지 않는다.

**이 기능은 조회 전용이다. 자동 삭제, 삭제 계획 승인·실행, 외부 AI 전송본 삭제 확인은 구현 완료로 간주하지 않는다.** 이번 변경에서 운영 자료 삭제와 자동 수집 재개는 실행하지 않는다.

## 남은 운영 조건

- 공급자별 상품 리서치 사용 목적·보존·재배포·AI 전송 조건에 대한 권한 있는 법무 검토
- 출처와 검수자를 확인한 정답 상품 50개 이상 및 실제 블라인드 평가자
- 출시 상품의 실제 매출·반품·마진 결과. 기존 다른 상품 판매 자료와 구분
- 쿠팡 파트너스 승인 후 키 발급 및 실제 인증 검증
- 검증 가능한 삭제 계획·실행 및 외부 복사본 처리 절차

공개 상품 후보, AI 평가, 과거 다른 상품 매출은 위 조건을 충족한 것으로 표시하지 않는다.

## 검증 방식

정책·저장 자료·API 회귀는 로컬 SQLite를 사용하며 공급자 HTTP와 인증은 모의 처리한다. 브라우저 검증은 실제 Chromium과 로컬 D1을 사용한다. 실제 공급자 인증 결과 및 운영 게시 상태는 별도로 기록한다.
