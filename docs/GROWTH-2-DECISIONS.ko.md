# 성장2 일일 결정·운영 교훈 — G2-11/31/32

원안 전체 개발 계속 지시에 따라 main `a733099`(#269 병합)에서 `codex/growth2-decisions`로 시작한다. 기존 상품·미션·구매 병목과 사업 관측을 결정 → 다음 행동 → 교훈 후보/시험/재사용/퇴역으로 연결한다. 이번 증분은 운영 기록이며 자동 일일 실행이나 전체 사업 목표 달성 판정이 아니다.

## 결정과 근거

유지·수정·중단·탐색·확대 검토를 구분하고, 관측·이유·대체 설명·다음 행동·담당 역할·기한과 현재 미션/병목 판을 기록한다. 확대는 별도 검증이 필요한 보류 항목이다. 인과 증명이나 대표의 새 라벨이 없어도 탐색과 오류 수정 결정을 기록할 수 있다. 실행 실패/결과 불명 미션에서도 중단·수정과 실패 교훈을 남길 수 있다.

서버가 연결 미션/병목/결정의 검증된 기록과 현재 캠페인 사업 집계를 스냅샷으로 고정하고 digest를 기록한다. 클라이언트가 보낸 성과 수치나 스냅샷으로 대체하지 않는다. 최신 조회와 당시 근거를 구분하며, 변경된 참조는 재검토 대상으로 표시한다. 미션 상위 오퍼·상품/확정 사실·고객 기회·시장 근거의 변경/삭제도 추적하되, 실행 준비 부족 자체로 실패 학습을 막지 않는다. 사업 집계의 미확인 값·주문 장부 관측·현금·인과 미측정을 그대로 보존한다.

## 운영 교훈

방법·가설·적용 범위·출처 유형·근거 등급·시험 계획/결과·반증 근거·폐기 조건·손실 한도·만료·후속 행동을 기록한다. 출처는 시장/실행/병목/결정/수동을 구분하고 기존 학습 규칙의 viral/store/review/preference/meta origin을 덮어쓰지 않는다.

상태는 후보(candidate), 시험(testing), 재사용 검토(reusable), 퇴역(retired)이며 결과는 미시험/성공/실패/무효다. 실패 결과도 재발 방지 교훈으로 재사용을 검토할 수 있다. 무효 시험·미시험·미확인 손실 한도·만료·근거 변경이나 필수 항목 누락은 재사용을 보류한다. 0원 손실 한도와 미확인(null)을 구분한다. 재사용 가능 표시는 범위 내 운영 참고 자격이며 자동 프롬프트 주입·active 규칙 승격이 아니다.

`mayExecute:false`, `mayScale:false`, `mayPromote:false`, `causalStatus:not_measured`의 해당 계약을 유지한다. 확증 결과를 요구하는 인과 라벨이나 자동 확대 승인으로 우회하지 않는다. 외부 고객 발송·게시·지출·계약을 수행하지 않는다.

## 저장과 화면

`GET/POST /api/growth/decisions`: `save_decision`·`save_lesson`. 관리자·CSRF·owner lock·캠페인/항목 CAS·동일 요청 멱등, 참조의 동일 소유자/브랜드/캠페인과 정확한 버전을 검사한다. 미션–병목–결정 사이의 참조도 일치해야 한다. 실행 준비도 부족을 학습 저장의 차단 이유로 전파하지 않는다.

`growth_decision`, `growth_lesson`과 각각의 추가 전용 history를 D1 batch로 저장한다. 종류별 캠페인당500개 제한이며 캠페인과 함께 삭제하는 로컬 기록이다. 기존 외부 실행·매출 원장의 삭제 보호는 유지한다. 작성 중 입력은 저장 실패와 새로고침에 보존하고, 버전 충돌은 명시적으로 최신 판을 채택한다. 일반 멤버와 보관 캠페인은 조회만 허용한다.

개인정보/인증정보를 입력하지 않으며 담당자는 역할로 기록한다. 입력 텍스트는 React 텍스트로 표시하고 외부 모델/API로 전송하지 않는다.
